Sky-Run-Game

Sky Run is a simple endless runner game made in Unity.

The player runs endlessly on floating roads while avoiding obstacles and collecting coins. The game includes lane switching, jumping, rolling, coin collection, power system, UI panels, and infinite road spawning.

Features
Endless runner gameplay
Infinite road generation
Lane switching system
Jump and roll mechanics
Coin collection system
Obstacle collision and hit animation
Power-up system with timer
Main Menu, HUD, Pause, and Game Over UI
Leaderboard and save system using PlayerPrefs
Controls
PC Controls
A / Left Arrow → Move Left
D / Right Arrow → Move Right
Space → Jump
S / Down Arrow → Roll
Built With
Unity 6
C#
