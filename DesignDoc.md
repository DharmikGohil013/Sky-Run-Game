# Design Document

## Game Name
Sky Run Game

## Genre
Endless Runner

## Platform
PC / Android

## Engine
Unity 6

## Gameplay
The player runs endlessly on floating roads while avoiding obstacles and collecting coins.

## Core Mechanics
- Forward movement
- Lane switching
- Jump system
- Roll system
- Coin collection
- Obstacle collision
- Infinite road spawning

## UI System
- Main Menu
- HUD
- Pause Panel
- Game Over Panel
- Shop Panel
- Leaderboard

## Power System
Players can collect and use powers during gameplay.

## Goal
Run as far as possible and collect maximum coins.
